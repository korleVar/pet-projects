# Данные на экранных формах классификаторов и справочников


Описываем **данные** на экранных формах **списка** (List) для классификаторов и справочников.  
Карточки (Card) подробно пойдут дальше (в Ex.05/06), здесь фиксируем ключевые правила валидации и представления.

---

## Общие принципы отображения данных

- **Неопределённые значения**: отображаются как `—` 
- **Выход за границы**: обрезка с `…` + tooltip по hover (или раскрытие строки).  
Пользователь наводит курсор на элемент  
Появляется небольшая всплывающая подсказка  
Исчезает при уходе курсора  
- **Булевы поля**: `Да/Нет` (чекбокс в таблице).
- **Телефон**: маска `+7 (___) ___-__-__` 
- **ID**: как правило скрыт, доступен в деталях/tooltip при необходимости.

## Унифицированные сообщения (для UX согласованности)

| Тип                       | Текст |
|---------------------------|---|
| Пустая выборка            | `Ничего не найдено` |
| Ошибка обязательного поля | `Поле "<Имя поля>" обязательно` |
| Ошибка формата            | `Некорректный формат значения` |
| Дубликат                  | `Запись с такими параметрами уже существует` |
| Запрет удаления (история) | `Удаление недоступно. Используйте деактивацию.` |
