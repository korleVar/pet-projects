# Exercise 02 — Актуализация UC

### UC04. Зарегистрировать клиента (менеджер)

**Контекст использования:** Менеджер, при общении с клиентом по телефону, регистрирует клиента, чтобы записать на обслуживание.

**Область действия:** барбершоп, оказание услуг клиентам.

**Уровень:** цель пользователя.

**Основное действующее лицо:** менеджер.

**Предусловия:** Клиент позвонил менеджеру. Менеджер зашел на сайт барбершопа.<p style="color: orange; "> В системе существует справочник «Канал связи» </p>

**Основной сценарий:**

| №   | Шаг                                                                                                                                                    | Компонент          | Роль     | Интеграция                   | Справочник  |
| :-- | :----------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------- | :------- | :--------------------------- | :---------- |
| 1   | Менеджер открывает страницу регистрации клиента и нажимает кнопку «Зарегистрировать клиента».                                                          | Клиент             | Менеджер |                              |             |
| 2   | Клиент запрашивает с сервера актуальный список каналов связи для заполнения выпадающего списка.                                                        | Клиент             | Система  | GET                          | Канал связи |
| 3   | Система отображает форму с полями: «Номер телефона», «Фамилия», «Имя», «Отчество», выпадающий список «Канал связи».                                    | Клиент             | Система  |                              | Канал связи |
| 4   | Менеджер заполняет поля (телефон, фамилия, имя, отчество, канал связи) и нажимает кнопку «Зарегистрировать».                                           | Клиент             | Менеджер |                              |             |
