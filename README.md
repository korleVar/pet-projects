## Структура и эволюция моих навыков

Мое обучение построено по принципу «от простого к сложному»:

### Фундамент анализа
- **Введение в бизнес-анализ** — основы профессии, роль аналитика в команде, ключевые зоны ответственности
- **Сбор и управление требованиями** — техники интервью, брейнсторминга, документирование требований (BRD, SRS)
- **Работа с заинтересованными сторонами** — коммуникация, эскалация, управление ожиданиями

### Моделирование и проектирование
- **Процессы и нотации** — BPMN, UML, IDEF0, моделирование "как есть" и "как будет"
- **Use Case и User Stories** — составление сценариев использования, Acceptance Criteria (Gherkin)
- **Прототипирование** — создание wireframes и мокапов (Figma, Draw.io)

### Системный анализ
- **API и интеграции** — REST, SOAP
- **Моделирование данных** — ER-диаграммы, нормализация, проектирование схем БД
- **Потоки данных** — DFD диаграммы, ETL/ELT процессы, интеграционные паттерны

### SQL и работа с данными
- **Основы SQL** — SELECT, фильтрация, сортировка, JOIN всех типов
- **Аналитические запросы** — агрегация (GROUP BY), оконные функции, подзапросы
- **Оптимизация** — индексы, EXPLAIN ANALYZE, рефакторинг "тяжелых" запросов
