## Структура и эволюция моих навыков

Мое обучение построено по принципу «от простого к сложному»:

### Фундамент SQL
- **Базовые запросы SELECT** — фильтрация (WHERE), сортировка (ORDER BY), работа с диапазонами (BETWEEN)
- **Форматирование вывода** — конкатенация строк, вычисляемые поля, кавычки и спецсимволы
- **Уникальные значения** — DISTINCT, фильтрация по нескольким условиям

### Подзапросы и операции с множествами
- **Подзапросы в SELECT и FROM** — вложенные запросы для извлечения данных
- **Условные выражения** — CASE, булевы поля
- **Операции над множествами** — UNION, EXCEPT, INTERSECT, работа с дубликатами

### JOIN и соединения таблиц
- **Различные типы JOIN** — INNER, LEFT, RIGHT, FULL, NATURAL, CROSS JOIN
- **Продвинутые соединения** — Semi Join, Anti Join
- **Работа с внешними ключами** — обеспечение ссылочной целостности

### Агрегация и аналитика
- **Агрегатные функции** — COUNT, SUM, AVG, MIN, MAX
- **Группировка** — GROUP BY, HAVING, фильтрация групп
- **Оконные функции** — ROW_NUMBER, RANK, OVER (PARTITION BY)

### Транзакции и изоляция
- **Уровни изоляции** — READ COMMITTED, REPEATABLE READ, SERIALIZABLE
- **Аномалии данных** — Lost Update, Dirty Reads, Non-Repeatable Reads, Phantom Reads
- **Deadlock** — воспроизведение и разрешение взаимоблокировок

### Оптимизация и индексы
- **Типы индексов** — B-Tree, функциональные, многоколоночные, частичные, уникальные
- **Анализ запросов** — EXPLAIN ANALYZE, поиск узких мест
- **Покрывающие индексы** — Index Only Scan

### Представления и материализованные представления
- **Виртуальные таблицы (VIEW)** — фильтрация, объединение данных
- **Материализованные представления** — кэширование тяжелых запросов, обновление (REFRESH)

### DML и модификация данных
- **Вставка данных** — INSERT INTO ... SELECT, массовые вставки
- **Обновление и удаление** — UPDATE, DELETE, каскадные операции
- **Триггеры и функции** — автоматизация аудита, бизнес-логика на уровне БД
