### Day 01 — Основы работы с множествами и JOIN

**UNION, EXCEPT, INTERSECT, декартово произведение и JOIN**

| Задание | Описание | Ключевые навыки |
|---------|----------|------------------|
| ex00 | UNION: ID и имена из menu и person | UNION, объединение таблиц |
| ex01 | UNION с сортировкой и дубликатами | UNION ALL, сортировка |
| ex02 | Уникальные названия пицц без DISTINCT | Альтернативы DISTINCT |
| ex03 | Пересечение: люди, которые и посетили, и заказали в один день | INTERSECT |
| ex04 | Разность множеств (MINUS) с дубликатами | EXCEPT ALL |
| ex05 | Декартово произведение (CROSS JOIN) | CROSS JOIN |
| ex06 | Имена людей вместо ID (из ex03) | JOIN, подзапросы |
| ex07 | Форматирование: "Andrey (age:21)" | Конкатенация, JOIN |
| ex08 | NATURAL JOIN вместо явного JOIN | NATURAL JOIN |
| ex09 | Пиццерии, которые никто не посещал (IN vs EXISTS) | IN, EXISTS, Anti Join |
| ex10 | Глобальный JOIN с тремя таблицами | Многотабличные JOIN |
