### Day 02 — Deep diving into JOINs

**Продвинутые JOIN, CTE, generate_series, обработка пропусков**

| Задание | Описание | Ключевые навыки |
|---------|----------|------------------|
| ex00 | Пиццерии, которые никто не посещал | LEFT JOIN + IS NULL |
| ex01 | Пропущенные даты посещений (1-10 января) | generate_series, NOT IN |
| ex02 | FULL JOIN с заменой NULL на '-' | FULL JOIN, COALESCE |
| ex03 | CTE вместо подзапроса (рефакторинг ex01) | WITH (CTE) |
| ex04 | Пиццы с грибами или пепперони | JOIN, фильтрация |
| ex05 | Женщины старше 25 лет | WHERE, ORDER BY |
| ex06 | Пиццы, заказанные Denis или Anna | JOIN, IN |
| ex07 | Самая дешевая пиццерия для Dmitriy | Многотабличные JOIN, подзапросы |
| ex08 | Мужчины из Москвы или Самары, заказавшие pepperoni/mushroom | JOIN, комбинированные условия |
| ex09 | Женщины, заказавшие и cheese, и pepperoni | Самосоединение (SELF JOIN) |
| ex10 | Люди из одного города (пары) | CROSS JOIN + условие |
